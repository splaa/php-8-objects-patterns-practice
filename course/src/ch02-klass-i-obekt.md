# 2. Класс, объект, конструктор, свойства, видимость

Класс — описание. Объект — экземпляр по этому описанию. `new Track(...)` создаёт объект: PHP выделяет память под свойства и вызывает `__construct()`.

Код главы: `course/code/Ch02/Track.php` и `course/code/Ch02/run.php`.

```bash
php course/code/Ch02/run.php
```

## Конструктор — единственная дверь

Конструктор отвечает за то, чтобы объект не существовал в недостроенном виде. Отсюда правило: всё, без чего объект бессмыслен, принимается конструктором, и там же проверяется.

```php
public function __construct(
    public readonly string $title,
    public readonly string $artist,
    private readonly int $seconds,
) {
    if ($seconds <= 0 || $seconds > self::MAX_SECONDS) {
        throw new InvalidArgumentException("Недопустимая длительность: {$seconds}");
    }

    self::$created++;
}
```

Здесь работает **продвижение свойств** (constructor property promotion, PHP 8.0): модификатор видимости прямо в сигнатуре объявляет свойство и присваивает ему аргумент. Три строки вместо девяти. Обратите внимание: тело конструктора всё равно выполняется — валидация и побочные эффекты никуда не делись.

Если проверка не прошла, конструктор бросает исключение, и объекта просто не возникает. Это ключевая мысль: невозможно получить `Track` с длительностью `0`, а значит, весь остальной код может не проверять этот случай.

## Видимость: `public`, `private`, `protected`

Видимость — не «безопасность», а договор. `public` — то, на что имеет право опираться чужой код; всё остальное вы вправе переписать завтра.

- `public readonly string $title` — читать можно всем, писать нельзя никому, даже классу-владельцу после конструктора.
- `private readonly int $seconds` — наружу отдаётся не число, а готовая строка `duration()`. Формат можно поменять, не сломав вызывающих.
- `private int $plays` — изменяемое состояние, но менять его можно только через метод `play()`. Счётчик не уедет в минус, потому что никто, кроме класса, до него не дотянется.

`protected` означает «для меня и наследников» — он понадобится в главе 3. По умолчанию начинайте с `private` и повышайте видимость, только когда появился реальный потребитель.

## Статика: у класса, а не у объекта

`self::$created` и `self::MAX_SECONDS` принадлежат классу целиком. Статическое свойство — общий счётчик на все экземпляры; константа класса — значение, которое незачем хранить в каждом объекте.

Внутри класса удобны `self::` и `static::`. Разница проявится при наследовании: `self` жёстко указывает на класс, где написан код, `static` — на класс, который реально вызван (позднее статическое связывание). В главе 8 на этом строится фабричный метод.

Статика соблазнительна и опасна: глобальное состояние трудно подменить в тесте. Держите её для счётчиков, констант и именованных конструкторов.

## Именованные конструкторы

У PHP один `__construct` на класс, а способов создать объект часто нужно несколько. Решение — статический метод с говорящим именем:

```php
public static function fromMinutes(string $title, string $artist, float $minutes): self
{
    return new self($title, $artist, (int) round($minutes * 60));
}
```

`Track::fromMinutes('Drift', 'Nadia Rue', 4.5)` читается лучше, чем `new Track('Drift', 'Nadia Rue', 270)`, и вся конвертация лежит внутри класса. Тип возврата `self` означает «этот же класс».

## Методы, которые отвечают на вопросы

`duration()` не хранит ничего — он выводит представление из состояния. Такие методы дешевле свойств: нечему рассинхронизироваться. `__toString()` — магический метод, PHP вызывает его, когда объект попадает в строковый контекст (`echo $track`). Удобно для вывода и логов, но не делайте в нём вычислений, которые могут упасть.

## Что стоит запомнить

Объект должен рождаться корректным и защищать своё состояние. Всё, что вы не пообещали наружу через `public`, остаётся вашей свободой. Читать — через методы, менять — через методы с осмысленными именами (`play()`, а не `setPlays()`).

## Упражнение

Добавьте в `Track`:

1. `private ?int $lastPlayedAt` (метка времени, `time()`), обновляемую в `play()`;
2. метод `wasPlayed(): bool`;
3. именованный конструктор `fromString(string $line): self`, разбирающий строку вида `Nadia Rue|Coastline|215` (подсказка: `explode` плюс проверка количества частей, иначе `InvalidArgumentException`);
4. константу `MIN_SECONDS = 1` и используйте её в валидации вместо `0`.

Проверьте в `run.php`: создайте трек из строки, вызовите `play()`, выведите `wasPlayed()` и убедитесь, что битая строка `Coastline` (без разделителей) даёт исключение.
