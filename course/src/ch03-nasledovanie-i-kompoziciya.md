# 3. Наследование и композиция

Два способа собрать сложное поведение из простого. Наследование говорит «я такой же, только с добавкой». Композиция — «у меня внутри есть помощник, которому я делегирую работу».

Код главы: `course/code/Ch03/`.

```bash
php course/code/Ch03/run.php
```

## Наследование: что реально происходит

```php
final class PodcastEpisode extends Track
{
    public function __construct(string $title, int $seconds, Source $source, private readonly string $show, private readonly int $number)
    {
        parent::__construct($title, $seconds, $source);
    }

    public function describe(): string
    {
        return sprintf('%s #%d: %s', $this->show, $this->number, parent::describe());
    }
}
```

Три вещи, которые нужно видеть в этом коде.

**Конструктор наследника не вызывается автоматически поверх родительского.** Если вы объявили свой `__construct`, родительский надо позвать руками через `parent::__construct(...)`. Забыли — свойства родителя останутся неинициализированными, и PHP 8 честно упадёт с `Error` при первом обращении к типизированному свойству.

**Переопределение меняет поведение для всех, кто держит ссылку на родительский тип.** Метод `play()` объявлен в `Track` и вызывает `$this->describe()`. Для эпизода подкаста будет вызван переопределённый `describe()` — хотя `play()` об этом ничего не знает. Так работает полиморфизм: решение принимается по фактическому классу объекта.

**`protected` — это для наследников.** `$title` и `$seconds` объявлены `protected`, потому что `PodcastEpisode::describe()` обращается к ним через `parent::describe()`. А `$source` остался `private`: наследнику он не нужен, значит, не его дело.

`final` перед классом означает «от меня не наследуют». Ставьте его по умолчанию: открытость к наследованию — это обязательство поддерживать свои внутренности в неизменном виде. `Track` оставлен не-`final` осознанно, потому что от него наследуются в этой же главе.

## Где наследование ломается

Добавьте к треку способ доставки: локальный файл и поток. Наследованием это выглядит так: `LocalTrack`, `StreamTrack`. Теперь добавьте подкаст — получаем `LocalPodcast`, `StreamPodcast`. Ещё одно измерение (например, платный/бесплатный) — и классов восемь. Комбинаторный взрыв.

Признак, что вы на этом пути: подклассы отличаются не поведением, а одним значением или одной подменяемой операцией; имя класса содержит два прилагательных; в базовом классе появляются методы, нужные только половине наследников.

## Композиция: вынести измерение в отдельный объект

```php
final class Source
{
    public static function file(string $path): self { /* ... */ }
    public static function stream(string $url): self { /* ... */ }

    public function open(): string
    {
        return match ($this->kind) {
            'file' => "читаю файл {$this->location}",
            'stream' => "подключаюсь к потоку {$this->location}",
        };
    }
}
```

`Track` теперь принимает `Source` в конструктор и делегирует: `$this->source->open()`. Комбинации перестали быть классами и стали аргументами. Подкаст с потоком — это `new PodcastEpisode(..., Source::stream($url), ...)`, а не новый класс. Второе измерение добавится ещё одним полем, а не удвоением иерархии.

Заодно тесты стали проще: чтобы проверить `Track::play()`, не нужен настоящий файл — достаточно подсунуть другой `Source`. Подмена зависимости снаружи и называется внедрением зависимости; в главе 7 мы разберём, почему это главный рычаг против жёсткого сцепления.

`Album` в примере — тоже композиция, только другого вида: он хранит список треков и не претендует быть треком. Альбом *имеет* треки, а не *является* треком.

## Как выбирать

Спросите себя, что вы утверждаете. «Эпизод подкаста — это трек, у которого дополнительно есть шоу и номер» — правда, и все методы трека для него осмысленны: подходит наследование. «Трек — это файл» — неправда; файл это то, чем трек пользуется: подходит композиция.

Практическое правило: наследование — для расширения типа, композиция — для подменяемых деталей. Если сомневаетесь, берите композицию: её всегда легче развернуть обратно.

## Упражнение

1. Добавьте `Source::silence()` — источник-заглушка без адреса, `open()` возвращает `тишина`. Убедитесь, что ни `Track`, ни `Album` менять не пришлось: это и есть выигрыш композиции.
2. Сделайте класс `LiveSet extends Track` с полем `venue` и переопределите `describe()` так, чтобы получалось `Coastline (живьём, Fabrika) [215 сек]`. Обязательно через `parent::describe()`.
3. Добавьте в `Album` метод `totalSeconds(): int`. Понадобится доступ к длительности — решите, что правильнее: сделать `$seconds` публичным, добавить в `Track` метод `seconds()` или считать иначе. Запишите в комментарии, почему выбрали свой вариант.
